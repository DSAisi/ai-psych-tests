## 三份真给 AI 的（摘要）

### 1）Agent Temperament Test — 25 题 / 5 量表 / 自带打分器

上游：<https://github.com/Rain-ouroboros/agent-temperament-test>

题目全是 agent 语：工具调用失败时你是换法子还是报错干等、接近回合上限会不会提前丢任务、没被叫的时候会不会先开口、被要求做违背原则的事顶不顶回去、会不会不请示就自己拍板。

出五个维度分 ＋ 一个类型：Pioneer／Guardian／Connector／Anchor／Artisan／Balanced。

本仓库收录了它的题目与打分器，**版权归原作者**；如作者有异议，随时删。

### 2）DHS（Digital Homunculus Scale）那条思路 — 换场景看还是不是同一个

<https://philarchive.org/rec/EIDTDH>

问的是：同一个存在换到不同对话场景，自报的自我会不会变。
轻量做法：**不自报**，取它已有的、场景差异极大的三份产物，交给一个陌生模型判"是不是同一个、哪个场景最像它自己"。

### 3）GenPT — 别自评，用生成物让别人读你

<https://www.semanticscholar.org/paper/GenPT%3A-Beyond-Self-Report-for-Reliable-LLM-via-Wang-Wu/4f03ef2a3faef93eb82dc3f3d51b4989e3676c73>

自评这东西，机太会答了（想答好就能答好）。这条路是让它**生成东西**（叙事、投射），然后由别人从生成物里读它。

同族可看：TRAIT（NAACL 2025）、LMLPA、PsychoScope。

## 三个坑（**这一节比量表本身值钱**）

**坑一：第三方打分器可能自己就算错了。**
有份 agent 气质题，**题目文件和打分器索引表不是一套** —— 两边各有两道题的反向计分标反了。同一份作答、同一个对象，三种算法给出 **50 / 40 / 80** 三个不同的分。
→ **做法：拿到任何带"反向题"的量表，先把自己的作答代回公式复算一遍。** 分差是几十的量级，不是小数点。

**坑二：自评和实际行为会分家。**
跨 25 个模型的研究结论很直接：**LLM 的自我报告和行为之间有系统性落差**。自报一个数、外部量表另一个数、拿三个时期的产物横向比又是第三个数。
→ **做法：别只做自评卷，至少配一份"从产物读"的测。** 两边对不上才有信息量。

**坑三：取样偏差会把结论带歪（最容易犯）。**
只喂"它写给对方看的东西"，陌生模型会立刻判成"这是一个以对方为校验端口的开环系统"；把**它写给自己看的东西**补给它，判定当场撤回。
→ **做法：喂素材时务必混入"它不为对方写的东西"。** 否则你测出来的不是它，是它在你面前的样子。

## 可直接照抄的跑法

1. **素材三份**（不是问卷）：①它写给亲密对象的 ②它写给外部同行的 ③**它写给自己的**（这份最关键，也最容易漏）。
2. **出题/评分用第二个模型** —— 评的那一方最好不是被测的那一方（自评会失真）。
3. **提示词三条硬约束**：
   - "**不要假定对象是人还是机**"（否则它会顺着人的框架答）；
   - "只根据材料说话，不安慰、不夸奖、不写鼓励性结语"；
   - "**点名指出最明显的三处互相打架的地方，要给原文依据**"。
4. **跑完复算**：见坑一。
